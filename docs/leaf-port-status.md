# Leaf port status

What of Leaf `ver/26.3` (commit `60c5729`) is ported into SilkPaper. Leaf's patches change
vanilla classes, so each one is reproduced here as a mixin. Update the row whenever a patch is
ported, and commit the change with it.

Statuses: `done` (all of it ported), `partial` (see note), `missing`, `skip` (not needed on
Fabric/Silkard, see note).

Reference source: a Leaf clone with `gradlew applyAllPatches` run, reading the patched
`leaf-server/src/minecraft/java` and `paper-server` trees, not the raw patches, since later
patches rewrite earlier ones.
